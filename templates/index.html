YOLO Object Detection

Please allow camera access and select a camera to start detection.

How to enable camera access:

  1. Make sure you're using a modern browser (Chrome, Firefox, Edge, or Safari)
  2. Check if your browser is blocking camera access (look for a camera icon in the address bar)
  3. Click the camera icon and select "Allow" for camera access
  4. If you don't see the camera icon, try refreshing the page
  5. Make sure no other application is using your camera
